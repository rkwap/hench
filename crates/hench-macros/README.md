# hench-macros

The `#[hench::job]` attribute macro of [hench](https://crates.io/crates/hench), a Redis-backed
background job system for Rust inspired by Sidekiq. Use it through the `hench` crate (its
default `macros` feature re-exports it as `hench::job`); see hench's documentation.
